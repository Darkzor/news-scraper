# Feedback

- Keep source files alongside generated bytecode in dev-pipeline attempts so fallback workers can inspect and repair implementation details without reverse-engineering caches.
- Leave generated frontend artifacts out of implementation handoffs; source, package metadata, and lockfiles are enough for fallback workers to repair and verify React scaffolds.
- Test runner tasks benefit from a repo-root command that can dispatch focused backend or frontend suites, so future automation does not need to know each package's working directory.
